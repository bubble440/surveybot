# SurveyBot — Plan anti-disqualification : Browser Fingerprint Spoofing

## Contexte
Objectif : réduire le taux de disqualification en **prod** à 0%.
Référence : le mode **attach** (mêmes proxies, disqualifications rares) est utilisé comme baseline.

## Différences identifiées et corrections à appliquer

### 1. 🔴 `navigator.userAgentData` — VIDE en prod
En prod, `navigator.userAgentData` retourne des champs vides/null alors qu'en attach il est complet. C'est une contradiction immédiate : l'UA annonce Chrome/Windows mais `userAgentData` ne confirme rien — détecté par tous les systèmes anti-bot modernes.

**Valeurs attach (référence) :**
- `platform` : `"Windows"`
- `brands` : `[Chrome 148, Chromium 148, Not-A.Brand 99]`
- `mobile` : `false`
- `architecture` : `"x86"`
- `bitness` : `"64"`
- `model` : `""`

**Fix à appliquer :**
```python
driver.execute_cdp_cmd("Page.addScriptToEvaluateOnNewDocument", {"source": """
Object.defineProperty(navigator, 'userAgentData', {
    get: () => ({
        brands: [
            { brand: "Chromium", version: "148" },
            { brand: "Google Chrome", version: "148" },
            { brand: "Not-A.Brand", version: "99" }
        ],
        mobile: false,
        platform: "Windows",
        architecture: "x86",
        bitness: "64",
        model: "",
        uaFullVersion: "148.0.7195.119"
    })
});
"""})
```

### 2. 🔴 Canvas Fingerprint — hash Linux vs Windows
Le canvas hash diffère complètement entre prod et attach car le rendu GPU sous Linux produit une image différente de Windows (anti-aliasing, couleurs).

| | Prod | Attach |
|---|---|---|
| Signature | `4CD01E2A…` | `C8FBD3F8…` |
| File Size | 6608 bytes | 5592 bytes |
| Nb Colors | 941 | 222 |
| OS détecté | GNU/Linux | Windows |

**Fix à appliquer :**
Hooker `toDataURL`, `toBlob` et `getImageData` avant chargement de page pour retourner le hash Windows. La dataURL base64 de référence doit être extraite du canvas attach.

```python
driver.execute_cdp_cmd("Page.addScriptToEvaluateOnNewDocument", {"source": """
(function() {
    const originalToDataURL = HTMLCanvasElement.prototype.toDataURL;
    HTMLCanvasElement.prototype.toDataURL = function(type) {
        if (this.width === 220 && this.height === 30) {
            return "<REMPLACER_PAR_DATAURL_BASE64_ATTACH>";
        }
        return originalToDataURL.apply(this, arguments);
    };
})();
"""})
```
⚠️ La dataURL de référence est à extraire manuellement depuis le canvas attach (F12 → Console → `document.querySelector('canvas').toDataURL()`).

### 3. 🟠 WebGL — paramètres résiduels non harmonisés
Le spoofing WebGL est partiellement appliqué mais les hashes diffèrent encore.

| Paramètre | Prod | Attach |
|---|---|---|
| Max Combined Texture Image Units | 70 | 32 |
| Extensions manquantes en prod | — | `WEBGL_provoking_vertex` |
| Chrome version UA | 149 | 148 |

**Fix :** harmoniser ces valeurs dans le script de spoof WebGL existant, et aligner la version Chrome (149→148) dans l'UA.

### 4. 🟡 Audio Sample Rate
| | Prod | Attach |
|---|---|---|
| Sample Rate | 44100 | 48000 |

Détectable via AudioContext fingerprinting.

**Fix :**
```python
driver.execute_cdp_cmd("Page.addScriptToEvaluateOnNewDocument", {"source": """
const origAudioContext = window.AudioContext || window.webkitAudioContext;
const OrigCtx = origAudioContext;
window.AudioContext = window.webkitAudioContext = function(...args) {
    const ctx = new OrigCtx(...args);
    Object.defineProperty(ctx, 'sampleRate', { get: () => 48000 });
    return ctx;
};
"""})
```
